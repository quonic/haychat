# Widgets Module

This module contains the code for the UI widgets used in the HayChat client. It includes the base `Widget` type, as well as specific widget types like `Panel`, `Label`, `Button`, and `FlexSpacer`. The module also includes functions for creating and managing widgets, as well as handling user input and rendering.

## Requirements

- `vendor:raylib`
