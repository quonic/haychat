# HayChat GitHub Issue Drafts

These files turn the `HC-###` backlog into GitHub-ready issue drafts. Each draft includes a suggested title, milestone, priority, dependencies, summary, deliverables, and acceptance criteria.

## Suggested Labels

- `planning`
- `release`
- `tester-readiness`
- `p0`
- `p1`
- `p2`
- `client`
- `server`
- `database`
- `docs`
- `packaging`
- `tests`
- `devex`

- [M2-reproducible-release-candidate.md](M2-reproducible-release-candidate.md)
- [M3-tester-handoff.md](M3-tester-handoff.md)

## Usage

1. Create matching GitHub milestones for `M0`, `M1`, `M2`, and `M3`.
2. Copy each draft into a new GitHub issue.
3. Apply labels from the suggested label list.
4. Preserve `HC-###` in the issue title or body so backlog and tracker stay aligned.
5. Keep dependency references in issue bodies until linked issues exist.
